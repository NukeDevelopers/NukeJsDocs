# API v2 迁移

API v2 是当前唯一支持的协议。旧版宿主 API 不提供兼容层。

## Manifest

```diff
 {
   "manifestVersion": 1,
-  "apiVersion": 1,
+  "apiVersion": 2,
   "permissions": {
-    "host": { "reflect": true },
+    "java": true,
+    "hook": true
   }
 }
```

## API 替换

| 旧接口 | v2 接口 |
| --- | --- |
| `nuke:host` | `nuke:java` |
| `HostObject.get()` | `object.field.value` |
| `HostObject.call()` | `object.method()` |
| `hostContext()` | `Java.context` |
| `hostClassLoader()` | `Java.classLoader` |
| `findClass()` | `Java.use()` |
| `hostConstruct()` | `Class.$new()` |
| `hostObjectRelease()` | `object.$dispose()` |

Java Bridge 调用改为同步；网络、文件、消息和 UI 仍按各自 API 返回 Promise。升级后重新打包 `.nsz`，并为危险权限重新确认。

## 升级顺序

1. 将 Manifest 的 `apiVersion` 更新为 `2`，删除旧的 `host` 权限声明；
2. 把 `nuke:host` 导入替换为 `nuke:java`，并为 Java/Hook 能力补充权限；
3. 将旧的异步宿主调用改为 Java Bridge 的同步字段、方法和构造调用；
4. 在[错误参考](/reference/errors)中补齐 `NukeError` 分支；
5. 重新打包并在应用中验证启动、停止、日志和权限撤销流程。
